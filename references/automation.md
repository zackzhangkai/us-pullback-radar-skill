# 每日自动化安装模板

## WorkBuddy（automation）/ 其他支持定时任务的智能体

把下面的模板交给你的智能体说「帮我建一个每天晚上 10 点的自动化任务，内容如下」，替换 **两处** ：监控对象、检查时间。

---

执行「美股回撤风险每日检查」任务（对象：{VOO / QQQM 及美股大盘}，用户长期持有）。

严格按 us-pullback-radar-skill skill（SKILL.md）执行：六类信号逐项获取最新数据 → 红黄绿灯分级 → 共振判定。

判定规则（严格）：

- 单一信号异常 = 正常波动，不产生任何对话提醒输出，仅在内部记录
- 只有当 ≥2 个独立风险信号同时共振，或监控对象距近期高点回撤超过 5% 且风险信号恶化时，才在对话中输出提醒
- 提醒形式：风险简报（≤300 字），列出共振信号、量化数据、风险等级和一句话建议；使用中文
- 取不到的数据标注「数据不可用」，不臆造数字
- 不共振时对话中只输出一行「今日检查完成，无共振风险信号」

---

## Claude Code / Codex（crontab 方式）

```bash
# crontab -e 添加（示例：每天 22:00）
0 22 * * * cd ~/projects/us-pullback-radar-skill && claude -p "按 SKILL.md 执行一次美股回撤风险检查，共振才输出简报" >> ~/.pullback-radar.log 2>&1
```

## ChatGPT / 无定时能力的智能体

无法后台定时的，用「每天打开对话说一句」的方式：

> 按 us-pullback-radar-skill 规则执行今日美股风险检查

（把 SKILL.md 正文贴到自定义指令 / Projects 的说明里，一次配置长期生效。）

## 校准

每两周回看一次记录：哪些共振瓦解了、哪些红灯没兑现？据此微调阈值（如把 Fed 概率红灯线从 60% 调到 70%）。这是这套规则越用越准的关键。
